# Useful materials, information, links, etc. for implementing a C compiler and/or any compiler
## Compiler implementation
- [ANSI C Yacc grammar](https://www.quut.com/c/ANSI-C-grammar-y.html) - it contains versions for `C9X` as well as for `C11`.
- [C standard specifications, revisions, ISO/IEC committee drafts](https://www.open-std.org/JTC1/SC22/WG14/www/projects#9899) - Contains a lot of C standard stuff. It doesn't have official ISO released standard specs but the drafts should serve the purpose.
